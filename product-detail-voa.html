可调光衰减仪 D-VAS08A

产品型号D-VAS08A
产品类型单模可调光衰减器

D-VAS08A 是一款 8 通道单模可调光衰减器 (VOA)，工作波长覆盖 1250~1650 nm， 最大衰减 40 dB，衰减设置分辨率 0.1 dB，衰减重复性 ≤ ±0.1 dB。 内置光功率监测功能，动态范围 -40~+20 dBm，精度 0.1 dB。 支持 SCPI 标准指令集，以太网 + 串口远程控制，适用于光纤通信系统功率均衡、 光模块测试、实验室精密测量等场景。

产品特性

  • ✓8 通道单模可调衰减，光纤类型 SMF (9/125)
  • ✓工作波长 1250~1650 nm，最大衰减 40 dB
  • ✓衰减设置分辨率 0.1 dB，衰减重复性 ≤ ±0.1 dB
  • ✓通道插入损耗 ≤ 1.3 dB（典型值），回波损耗 ≥ 50 dB
  • ✓内置光功率监测: 动态范围 -40~+20 dBm，精度 0.1 dB
  • ✓最大输入光功率 23 dBm
  • ✓FC/UPC 光接口，SCPI 指令集，以太网 + 串口远程控制
  • ✓台式 / 模块化封装，300 x 350 x 45 mm，1.2 kg

可调光衰减仪 D-VAS08B

产品型号D-VAS08B
产品类型单模可调光衰减器

D-VAS08B 与 D-VAS08A 拥有相同的核心衰减性能，主要区别在于光接口采用 FC/APC（斜端面）， 具有更高的回波损耗性能，适合对后向反射敏感的高精度测试场景。 同样具备 8 通道单模可调衰减、40 dB 衰减范围、内置光功率监测等完整功能。

产品特性

  • ✓8 通道单模可调衰减，光纤类型 SMF (9/125)
  • ✓工作波长 1250~1650 nm，最大衰减 40 dB
  • ✓衰减设置分辨率 0.1 dB，衰减重复性 ≤ ±0.1 dB
  • ✓通道插入损耗 ≤ 1.3 dB（典型值），回波损耗 ≥ 50 dB
  • ✓内置光功率监测: 动态范围 -40~+20 dBm，精度 0.1 dB
  • ✓最大输入光功率 23 dBm
  • ✓FC/APC 斜端面光接口，更高的回波损耗性能
  • ✓SCPI 指令集，以太网 + 串口远程控制
  • ✓台式 / 模块化封装，300 x 350 x 45 mm，1.2 kg
