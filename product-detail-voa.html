可调光衰减仪 D-VAS08A

产品型号D-VAS08A
产品类型单模可调光衰减器

D-VAS08A 是一款 8 通道单模可调光衰减器 (VOA)，工作波长覆盖 1250~1650 nm， 最大衰减 40 dB，衰减设置分辨率 0.1 dB，衰减重复性 ≤ ±0.1 dB。 内置光功率监测功能，动态范围 -40~+20 dBm，精度 0.1 dB。 支持 SCPI 标准指令集，以太网 + 串口远程控制，适用于光纤通信系统功率均衡、 光模块测试、实验室精密测量等场景。

产品特性

  • ✓8 通道单模可调衰减，光纤类型 SMF (9/125)
  • ✓工作波长 1250~1650 nm，最大衰减 40 dB
  • ✓衰减设置分辨率 0.1 dB，衰减重复性 ≤ ±0.1 dB
  • ✓通道插入损耗 ≤ 1.3 dB（典型值），回波损耗 ≥ 50 dB
  • ✓内置光功率监测: 动态范围 -40~+20 dBm，精度 0.1 dB
  • ✓最大输入光功率 23 dBm
  • ✓FC/UPC 光接口，SCPI 指令集，以太网 + 串口远程控制
  • ✓台式 / 模块化封装，300 x 350 x 45 mm，1.2 kg

可调光衰减仪 D-VAS08B

产品型号D-VAS08B
产品类型单模可调光衰减器

D-VAS08B 与 D-VAS08A 拥有相同的核心衰减性能，主要区别在于光接口采用 FC/APC（斜端面）， 具有更高的回波损耗性能，适合对后向反射敏感的高精度测试场景。 同样具备 8 通道单模可调衰减、40 dB 衰减范围、内置光功率监测等完整功能。

产品特性

  • ✓8 通道单模可调衰减，光纤类型 SMF (9/125)
  • ✓工作波长 1250~1650 nm，最大衰减 40 dB
  • ✓衰减设置分辨率 0.1 dB，衰减重复性 ≤ ±0.1 dB
  • ✓通道插入损耗 ≤ 1.3 dB（典型值），回波损耗 ≥ 50 dB
  • ✓内置光功率监测: 动态范围 -40~+20 dBm，精度 0.1 dB
  • ✓最大输入光功率 23 dBm
  • ✓FC/APC 斜端面光接口，更高的回波损耗性能
  • ✓SCPI 指令集，以太网 + 串口远程控制
  • ✓台式 / 模块化封装，300 x 350 x 45 mm，1.2 kg

可调光衰减仪 D-VAS16A

产品型号D-VAS16A
产品类型16 通道单模可调光衰减器

D-VAS16A 是一款 16 通道单模可调光衰减仪 (VOA)，工作波长覆盖 1250~1650 nm， 最大衰减 40 dB，衰减设置分辨率 0.1 dB，衰减可重复性 < 0.1 dB。 具备出色的光谱均匀度与低插入损耗，支持光关断开关、输入输出端功率监控与输出端恒定功率控制。 内置光功率监测动态范围 -35~+20 dBm，精度 0.1 dB，最大输入光功率 23 dBm。 支持 SCPI 标准指令集，以太网 + 串口远程控制，适用于 PON/FTTx R-OLT 测量与监控、 光器件与模块生产测试、光传感系统、城域网光层动态重构及科研测试等场景。

产品特性

  • ✓16 通道单模可调衰减，光纤类型 SMF (9/125)
  • ✓工作波长 1250~1650 nm（最小 1 nm 调整间隔），最大衰减 40 dB
  • ✓衰减设置分辨率 0.1 dB，衰减可重复性 < 0.1 dB（恒温、100 次重复设置）
  • ✓通道插入损耗 1.5 dB（典型值，1310/1550 nm 处测得），开关隔离度 50 dB（典型值）
  • ✓光关断开关功能、输入输出端功率监控、输出端恒定功率
  • ✓内置光功率监测: 动态范围 -35~+20 dBm，精度 0.1 dB
  • ✓最大输入光功率 23 dBm
  • ✓FC/UPC 光接口（同系列另有 FC/APC 版本 D-VAS16B 可选）
  • ✓SCPI 指令集，以太网 + 串口远程控制
  • ✓台式封装，430 x 450 x 45 mm，2.5 kg
